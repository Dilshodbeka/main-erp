# Политика конфиденциальности системы «Aliya ERP»

*Черновик. Редакция от [дата]. Требует проверки юристом.*

## 1. Кто обрабатывает данные
Оператор: [наименование / Ф.И.О., ИНН, адрес] (далее — «Оператор»). Контакт по вопросам данных: [e-mail / телефон].

## 2. Какие данные обрабатываются
- **Учётная запись:** адрес электронной почты, имя, роль в предприятии. Пароли хранятся только в зашифрованном (хешированном) виде.
- **Данные предприятия, которые вносит пользователь:** клиенты (имя, телефон, адрес), сотрудники (имя, оклад и выплаты), заказы, склад, касса, поставщики, переписка по заказам, файлы и изображения.
- **Telegram:** идентификатор чата клиента или руководителя — только если чат привязан пользователем.
- **Уведомления:** технический адрес подписки браузера для отправки уведомлений.
- **Посещаемость (если подключён сервис учёта рабочего времени):** отметки прихода и ухода сотрудников, получаемые от этого сервиса.
- **Технические данные:** сведения об ошибках приложения без имён, телефонов и сумм.

## 3. Зачем
Данные обрабатываются только для работы системы: ведения учёта предприятия, разграничения доступа, отправки уведомлений и сообщений по поручению пользователя, резервного копирования, устранения ошибок. Данные не продаются и не используются для рекламы.

## 4. Кто отвечает за данные клиентов и сотрудников предприятия
Сведения о клиентах и сотрудниках вносит предприятие-пользователь. Оно определяет цели их обработки и отвечает за наличие законных оснований (договор, согласие). Оператор обрабатывает эти данные по поручению предприятия.

## 5. Где хранятся данные и кому передаются
- База данных и вход в систему: [поставщик облачной базы данных, страна размещения серверов].
- Размещение приложения: [поставщик хостинга, страна].
- Сообщения: Telegram — только сообщения, которые пользователь сам отправляет через систему.
- Другим лицам данные передаются только по требованию закона.

*Для юриста: проверить соответствие требованию о хранении персональных данных граждан Узбекистана на территории страны и при необходимости изменить размещение.*

## 6. Защита
Данные каждого предприятия изолированы от других; доступ сотрудников ограничен ролями; соединение шифруется; ежедневно создаётся резервная копия; записи учёта не удаляются, а исправляются отменой, что сохраняет историю изменений.

## 7. Срок хранения
Пока действует учётная запись предприятия и [90] дней после прекращения использования, если закон не требует иного. По запросу владельца предприятия данные удаляются раньше.

## 8. Права пользователя
Пользователь вправе получить сведения о своих данных, исправить их, выгрузить данные предприятия средствами системы, отозвать согласие и потребовать удаления, обратившись по контакту из раздела 1.

## 9. Изменения
Новая редакция публикуется на сайте. О существенных изменениях пользователи уведомляются в системе.
