# Юридические документы (черновики)

- `oferta.md` — публичная оферта на подписку.
- `privacy.md` — политика конфиденциальности.

Это рабочие черновики, подготовленные не юристом. Перед публикацией:

1. заполните все поля в квадратных скобках (`[…]`) — реквизиты, цены, контакты;
2. покажите тексты юристу, знакомому с законодательством Республики Узбекистан
   (Гражданский кодекс — публичная оферта; Закон «О персональных данных» — в том числе требование
   хранить персональные данные граждан Узбекистана на серверах на территории страны; Закон «О защите прав потребителей»);
3. подготовьте версию на государственном (узбекском) языке;
4. после проверки разместите тексты на сайте и добавьте ссылки на экран регистрации.

Пока документы не опубликованы, ссылок на них в приложении нет.
