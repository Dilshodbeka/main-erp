# Перевод интерфейса (русский)

Исходный язык интерфейса — узбекский. Перевод накладывается поверх страницы по словарю,
ключ которого — узбекская строка (`src/translate.ts`).

- `uz-keys.json` — пронумерованный список строк интерфейса (номер = индекс в массиве).
- `ru-N.tsv` — перевод партиями: `номер<TAB>перевод`. Служебные строки пропущены.
- `ru-extra.tsv` — `узбекская строка<TAB>перевод` для строк вне списка (короткие слова, единицы, новые тексты).
- `npm run build:i18n` собирает из них `src/locales/ru.json` и проверяет плейсхолдеры `{0}`.

Новый текст в интерфейсе: добавьте строку в `ru-extra.tsv` и выполните `npm run build:i18n`.
Без перевода строка просто остаётся узбекской. Переключатель языка — на экране входа и в боковом меню;
выбор хранится в браузере. Сообщения Telegram-бота и печатные документы остаются на узбекском.
