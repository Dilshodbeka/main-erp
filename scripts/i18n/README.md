# Перевод интерфейса (русский)

Исходный язык интерфейса — узбекский. Перевод накладывается поверх страницы по словарю,
ключ которого — узбекская строка (`src/translate.ts`).

- `uz-keys.json` — пронумерованный список строк интерфейса (номер = индекс в массиве).
- `ru-N.tsv` — перевод партиями: `номер<TAB>перевод`. Служебные строки пропущены.
- Готовый словарь собирается из этих файлов в `src/locales/ru.json` после перевода всех партий.

Состояние: переведены строки 0–719 из 2480. Переключатель языка появится в интерфейсе,
когда словарь будет полным, — чтобы не показывать пользователям смесь языков.
